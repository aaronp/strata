# Layouts per Slide Type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Named, editable layouts matched to a slide's signature (its counted content elements by style), with deck defaults per signature, per-slide `custom` tracking, Apply / Apply to all / Reset / Save as layout / Update layout, and a Layout panel that shows matches, counts and slide lists. They replace the old content-rebuilding presets.

**Architecture:**
- **Pure functions at module level in `design/strata.dc.html`:** `BUILTIN_LAYOUTS`, `counted`, `keyOf`, `sigOf`, `sigKey`, `fillSlots`, `slotsOf`. They're exposed on `Component.lay` for tests.
- **Methods:** `layouts()` (memoised merge), `effectiveLayout(id)`, `isCustom(id)`, `markCustom()` (in `componentDidUpdate`, with an `allowLayout` token), and the actions (`applyLayout`, `applyToAll`, `resetToDefault`, `saveAsLayout`, `updateLayoutFrom`, `renameLayout`, `deleteLayout`).
- **The Layout tab template** is rebuilt.

**Tech Stack:** The Design Component app; Bun tests (`app.test.ts`).

**Spec:** `docs/superpowers/specs/2026-10-09-layouts-design.md`

## Global Constraints
- **Counted layers:** visible text layers without a layer-level `link`, plus visible image layers.
- **Key:** the style id if the style exists and isn't deleted, else `text`; `image` for images.
- **`sigKey`:** sorted `k:n` joined with `,`.
- **Slot filling:** groups are sorted by `y` then `x`. Only `x, y, w, h, rot` change.
- **Layouts never act on multi-frame or linked-in (`_from`) slides.** ROOT counts only when `titlePage` is on.
- **Each action** that changes `nodes` names its commit with `allowLayout(nodes)`. `layouts`/`layoutDefaults` edits are not on undo.
- **Tests:** run with `bun test`. The baseline is 215 passing.

## Review Focus
1. **`markCustom` vs other automatic node changes** (graft installs, the link-list importer, style deletes writing values, `chooseStyle` Custom, `deleteStyle`). Expected: only geometry edits of kept counted layers mark custom, and style/text-only edits never do.
2. **A burst of drags.** Expected: `custom` merges into the first edit's undo step (450 ms grouping), and undo removes both.
3. **`updateLayoutFrom` under React batching.** Expected: it uses the new layout object it built, not `this.layouts()` read after a `setState`.
4. **The panel's per-render `effectiveLayout` for every node** (cost on big decks). Expected: fine at ~500 slides. Mark it with `ponytail:`.
5. **A slide whose signature changed after a layout was applied.** Expected: the status reflects the new signature's default, and nothing moves until an action.

```js
  markCustom() {
```

```js
  // A layout applied to one node: its single frame's counted boxes; layout recorded, custom cleared. Null for multi-frame / linked-in slides.
  layoutPatch(n, L) { const fr = this.framesOfNode(n); if (!L || n._from || fr.length !== 1) return null;
    const boxes = fillSlots(fr[0].layers, L, this.styles()), { custom: _c, layers: _l, ...rest } = n;
    return { ...rest, frames: [{ ...fr[0], layers: fr[0].layers.map(l => (boxes[l.id] ? { ...l, ...boxes[l.id] } : l)) }], layout: L.id }; }
  applyLayout(id, lid) { const p = this.layoutPatch(this.state.nodes[id], this.layouts()[lid]); if (!p) return; const nodes = { ...this.state.nodes, [id]: p }; this.allowLayout(nodes); this.setState({ nodes }); }
  ownSlideIds() { return Object.keys(this.state.nodes).filter(k => !this.state.nodes[k]._from && (k !== 'ROOT' || this.state.titlePage)); }
  // Make L the default for its type and lay out every default (non-custom, single-frame) slide of that type.
  applyToAll(lid) {
    const L = this.layouts()[lid]; if (!L) return; const sig = sigKey(L.match), N = this.state.nodes, nodes = { ...N }; let updated = 0, kept = 0;
    for (const k of this.ownSlideIds()) { if (this.slideSig(k) !== sig) continue; if (this.isCustom(k)) { kept++; continue; } const p = this.layoutPatch(N[k], L); if (p) { nodes[k] = p; updated++; } }
    this.allowLayout(nodes); this.setState(s => ({ nodes, layoutDefaults: { ...(s.layoutDefaults || {}), [sig]: lid } }));
    this.flash('Updated ' + updated + ' slide' + (updated === 1 ? '' : 's') + ' · kept ' + kept + ' custom');
  }
  resetToDefault(id) { const sig = this.slideSig(id), L = this.layouts(), fits = x => x && sigKey(x.match) === sig;
    const d = fits(L[(this.state.layoutDefaults || {})[sig]]) ? L[(this.state.layoutDefaults || {})[sig]] : Object.values(L).find(fits); if (d) this.applyLayout(id, d.id); }
  saveAsLayout(id) {
    const fr = this.framesOf(id), layers = fr[0] ? fr[0].layers : [], match = sigOf(layers, this.styles()); if (!sigKey(match)) { this.flash('Nothing on this slide to lay out'); return null; }
    const L = this.layouts(), names = Object.values(L).map(x => x.name); let n = 1; while (names.includes('Layout ' + n)) n++;
    const name = 'Layout ' + n; let lid = 'layout-' + n, i = 2; while (L[lid]) lid = 'layout-' + n + '-' + i++;
    this.setState(s => ({ layouts: { ...(s.layouts || {}), [lid]: { name, match, slots: slotsOf(layers, this.styles()) } } }));
    const { custom: _c, ...rest } = this.state.nodes[id], nodes = { ...this.state.nodes, [id]: { ...rest, layout: lid } }; this.allowLayout(nodes); this.setState({ nodes });
    return lid;
  }
  // The slide's effective layout takes this slide's boxes; every default slide using it follows. Uses the new layout object directly (no read-after-setState).
  updateLayoutFrom(id) {
    const L0 = this.effectiveLayout(id); if (!L0 || this.framesOf(id).length !== 1) return;
    const { id: lid, ...stored } = { ...L0, slots: slotsOf(this.framesOf(id)[0].layers, this.styles()) }, L = { id: lid, ...stored };
```
